# KyoSys Engineering Standards (for a little more thought later xD)

This repository contains the organisation-wide development,
security and contribution standards used across KyoSys repositories.

## Shared Standards

- Contribution workflow
- Security policy
- Pull Request standards
- Issue templates
- Architecture change process
- Security engineering workflow

Repository-specific ownership, architecture and implementation
documentation remain within the applicable repository.

## Development Principles

KyoSys follows:

- issue-first development
- documentation-led design
- protected main branches
- peer-reviewed Pull Requests
- security and privacy review
- least privilege
- no secrets in source control
- traceable architecture decisions
